# Firework Protection Simulator

**Firework Protection Simulator** — образовательный VR-симулятор безопасного обращения с пиротехническими изделиями.

Проект представляет собой интерактивную трёхмерную среду, в которой пользователь сталкивается с различными ситуациями, связанными с запуском фейерверков, поведением окружающих и соблюдением правил безопасности.

Основная задача симулятора — показать последствия неправильного обращения с пиротехникой и научить пользователя распознавать опасные ситуации.

## Назначение проекта

Пиротехнические изделия могут стать причиной ожогов, травм, пожаров и других происшествий при несоблюдении правил эксплуатации.

Обычные инструкции часто воспринимаются формально, поэтому проект использует интерактивный формат обучения. Пользователь не просто читает правила, а оказывается внутри смоделированной ситуации, наблюдает за действиями персонажей и принимает решения.

Симулятор может использоваться:

- в образовательных учреждениях;
- на занятиях по основам безопасности жизнедеятельности;
- для проведения профилактических мероприятий;
- на выставках и демонстрациях VR-технологий;
- как учебный пример разработки VR-приложения на Unity.

## Сценарии

В симуляторе представлены ситуации, в которых персонажи нарушают правила безопасного обращения с пиротехникой.

Среди сценариев могут встречаться:

- ребёнок с пиротехнической ракетой;
- запуск фейерверка в неподходящем месте;
- нахождение людей рядом с пиротехникой;
- неправильная установка пиротехнического изделия;
- попытка повторного запуска несработавшего фейерверка;
- использование пиротехники несовершеннолетними;
- курение рядом с потенциально опасными объектами;
- опасное поведение окружающих;
- игнорирование требований безопасности.

Пользователь должен оценить происходящее и определить, какие действия являются опасными.

Диалоги используются для передачи контекста сценария.

Через разговоры пользователь может понять:

- какие правила они игнорируют;

Диалоги также позволяют выстраивать последовательные сценарии, а не ограничиваться статическим набором объектов.

## Требования

Для запуска потребуются:

- Unity Hub;
- Unity `6000.0.40f1`;
- Git;

## Клонирование

```bash
git clone https://github.com/DmitriyYakubovskiy/FireworkProtectionSimulator.git
cd FireworkProtectionSimulator
```

Репозиторий содержит большое количество трёхмерных моделей, текстур, звуков и других ресурсов, поэтому его размер значительно больше обычного программного проекта.

## Открытие проекта

1. Установите Unity Hub.
2. Установите Unity `6000.0.40f1`.
3. Откройте Unity Hub.
4. Нажмите **Add project from disk**.
5. Выберите папку репозитория.
6. Дождитесь импорта ресурсов.
7. Убедитесь, что все XR-пакеты успешно установлены.
8. Откройте основную сцену.
9. Подключите VR-устройство.
10. Нажмите **Play**.

## Настройка Oculus

Перед запуском проверьте:

- установлено ли приложение Meta Quest Link;
- подключён ли VR-шлем;
- разрешён ли режим Link или Air Link;
- выбрана ли среда OpenXR;
- активирован ли Oculus Runtime;
- установлен ли XR Plugin Management;
- включён ли нужный XR-провайдер.

При использовании OpenXR:

```text
Edit
→ Project Settings
→ XR Plug-in Management
→ OpenXR
```

При использовании Oculus XR Plugin:

```text
Edit
→ Project Settings
→ XR Plug-in Management
→ Oculus
```

Не следует одновременно включать несовместимые XR-провайдеры.

## Сборка проекта

### Сборка для Windows VR

1. Откройте проект в Unity.
2. Перейдите в:

```text
File → Build Profiles
```

3. Выберите Windows.
4. Установите архитектуру `x86_64`.
5. Добавьте необходимые сцены.
6. Убедитесь, что XR-провайдер активен.
7. Нажмите **Build**.
8. Выберите каталог для сборки.

### Сборка для Meta Quest

Для автономной сборки потребуется переключить проект на Android.

Необходимо:

- установить Android Build Support;
- установить Android SDK и NDK через Unity Hub;
- переключить Build Profile на Android;
- настроить OpenXR или Oculus;
- выбрать архитектуру ARM64;
- указать минимальную версию Android;
- выполнить сборку APK.

Не все ресурсы и настройки проекта обязательно оптимизированы для автономного запуска на Meta Quest.

## Оптимизация

Поскольку VR требует высокой и стабильной частоты кадров, для проекта особенно важна оптимизация.

Рекомендуется:

- ограничивать количество частиц;
- использовать Object Pooling для ракет и эффектов;
- уменьшать число прозрачных материалов;
- использовать LOD Group;
- запекать освещение;
- объединять статические объекты;
- применять Occlusion Culling;
- сокращать число источников света;
- использовать сжатие текстур;
- уменьшать разрешение тяжёлых моделей;
- отключать невидимые объекты;
- контролировать количество активных Animator;
- проверять производительность через Unity Profiler.

## Правила безопасности

Симулятор не заменяет официальные инструкции производителя пиротехники.

В реальной жизни необходимо:

- использовать только сертифицированную пиротехнику;
- читать инструкцию перед запуском;
- не давать пиротехнику детям;
- не запускать изделия в помещении;
- соблюдать безопасное расстояние;
- не держать запускаемое изделие в руках;
- не направлять пиротехнику на людей;
- не разбирать пиротехнические изделия;
- не возвращаться сразу к несработавшему изделию;
- не использовать пиротехнику рядом с огнём;
- учитывать ветер и окружающие объекты.
